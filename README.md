# OLX Desktop Clone

A desktop-based OLX Clone developed using **Python**, **Tkinter**, and **SQLite**. This project allows users to register, log in, sell products, browse available products, search items, filter by category, and buy products through a simple desktop interface.

## Features

* User Registration
* User Login
* Delete Account
* Sell Products
* Upload Product Images
* View Products
* Search Products
* Category Filter
* Buy Products
* Sold Out Status
* Modern Tkinter GUI
* SQLite Database Integration

## Installation

1. Clone the repository.
2. Install the required package:

```
pip install -r requirements.txt
```

3. Run the project:

```
python Gui.py
```
